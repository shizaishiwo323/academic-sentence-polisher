# Simple Word Replacement

## Purpose

Replace unnecessarily complex, rare, or AI-like words with clear academic alternatives.

Do not simplify standard technical terms. Only replace words that make the sentence less clear without adding precision.

## Core Rule

Prefer a simpler word only when it preserves:

- the same scientific meaning;
- the same evidence strength;
- the same technical relation;
- the same scope and uncertainty.

If the replacement may change the meaning, keep the original word or mark `author-confirm`.

## Common Replacements

| Avoid or use with caution | Prefer |
|---|---|
| `elucidate` | `show`, `explain` |
| `delineate` | `define`, `separate`, `distinguish` |
| `facilitate` | `support`, `help`, `allow` |
| `utilize` | `use` |
| `leverage` | `use` |
| `manifest as` | `appear as`, `produce`, `take the form of` |
| `commence` | `begin`, `start` |
| `terminate` | `end` |
| `necessitate` | `require` |
| `possess` | `have` |
| `prior to` | `before` |
| `subsequent to` | `after` |
| `in order to` | `to` |
| `owing to the fact that` | `because` |
| `with regard to` | `about`, `for` |
| `in the context of` | `in`, `for` |
| `a number of` | `several` |
| `the majority of` | `most` |
| `is capable of` | `can` |
| `gives rise to` | `produces`, `forms`, `leads to` |
| `is indicative of` | `indicates` |
| `substantiate` | `support` |
| `underscore` | `show`, `highlight`, or delete |
| `shed light on` | `show`, `explain`, `help explain` |
| `offer insights into` | state the specific finding |
| `serve as a basis for` | `support`, `provide`, or delete |

## Do Not Oversimplify These Technical Words

| Keep | Reason |
|---|---|
| `permeability` | Standard technical property |
| `porosity` | Standard technical property |
| `tortuosity` | Standard hydraulic metric |
| `transverse relaxation` | Standard NMR term |
| `matrix` | Standard pore-system term |
| `vug` | Standard carbonate pore term |
| `advection` | Standard transport process |
| `diffusion` | Standard transport process |
| `reaction kinetics` | Standard process term |
| `breakthrough` | Standard flow or reactive-transport term |
| `inversion` | Standard NMR or data-processing term |
| `interface retreat` | Standard dissolution term |

## Nominalization Reduction

| Wordy version | Clearer version |
|---|---|
| `the occurrence of dissolution` | `dissolution` |
| `the establishment of a conduit` | `a conduit forms`, `the conduit forms` |
| `the development of wormholes` | `wormholes develop` |
| `the expansion of the channel` | `the channel expands` |
| `the emergence of peak separation` | `peaks separate` |
| `the reduction of tortuosity` | `tortuosity decreases` |
| `the enhancement of permeability` | `permeability increases` |
| `the interpretation of T2 evolution` | `interpreting T2 evolution` |

## Prefer Direct Verbs

| Instead of | Use |
|---|---|
| `plays an important role in` | `contributes to`, `controls`, `affects` |
| `has the ability to` | `can` |
| `provides evidence for` | `supports` |
| `is associated with` | `accompanies`, `corresponds to`, `is linked to` |
| `thereby revealing` | `indicating`, `suggesting`, or split the sentence |

Choose the direct verb that matches the original scientific relation. Do not use `controls`, `causes`, or `drives` unless the original evidence supports causality.
