# Plain Scientific Vocabulary

Prefer a simpler word only when it preserves technical meaning, evidence strength, scope, and uncertainty.

## Common replacements

| Use with caution | Often clearer |
|---|---|
| `utilize` | `use` |
| `leverage` | `use` |
| `elucidate` | `show`, `explain` |
| `delineate` | `define`, `separate`, `distinguish` |
| `facilitate` | `support`, `help`, `allow` |
| `commence` | `begin`, `start` |
| `terminate` | `end` |
| `necessitate` | `require` |
| `prior to` | `before` |
| `subsequent to` | `after` |
| `in order to` | `to` |
| `owing to the fact that` | `because` |
| `the majority of` | `most` |
| `is capable of` | `can` |
| `is indicative of` | `indicates` |
| `shed light on` | state what was shown or explained |
| `offer insights into` | state the specific finding |

## Nominalization repair

- `the occurrence of dissolution` -> `dissolution`
- `the reduction of porosity` -> `porosity decreased`
- `the implementation of the algorithm` -> `we implemented the algorithm`
- `the comparison of A and B` -> `we compared A and B`

Retain nominalizations that name established technical processes or when the process itself is the topic.

## Technical-term protection

Do not simplify a recognized field term merely because it is unfamiliar. If a replacement may change the concept, keep the original or mark `author-confirm`.
