# Terminology Definition Rules

Use this file when polishing sentences that introduce or rely on technical terms, metrics, regimes, named relations, or manuscript-specific phrases.

## Core Rule

Define central non-obvious terms at first meaningful use. Do not invent definitions. If the required definition is not explicit in the source text, mark `author-confirm`.

## When to Define

Define a term when it is:

- central to the sentence or paragraph argument;
- a new metric, index, profile, map, law, model, framework, or regime;
- manuscript-specific rather than field-standard;
- needed to interpret a result, figure, equation, or comparison;
- likely to confuse a reader if left unexplained.

Do not define a term when it is:

- standard for the target audience;
- already defined nearby;
- used only once and can be replaced by plain wording;
- part of an equation, citation title, figure label, or established method name that should remain unchanged.

## Definition Patterns

Use short local definitions:

- `X refers to Y.`
- `X is defined as Y.`
- `Here, X denotes Y.`
- `We use X to represent Y.`
- `X, defined here as Y, ...`
- `This relation, known as X, relates A to B through C.`
- `X is characterized by Y under condition Z.`

For variables and equations:

- `X = A/B, where A is ... and B is ...`
- `Here, X denotes ..., and Y represents ...`
- `The X number compares A with B.`

For regimes:

- `The X regime is characterized by Y.`
- `X occurs when Y exceeds Z.`
- `In the X case, Y remains ..., whereas Z ...`

## Avoid

Avoid:

- introducing a new term to sound sophisticated;
- naming a relation that can be stated plainly;
- defining a term with another undefined abstract term;
- adding a mechanism inside a definition unless the mechanism is already in the source text;
- using `framework`, `paradigm`, `bridge`, `nexus`, or `pipeline` without inputs, operations, and outputs.

## Safe Rewrites

| Risky form | Safer rewrite |
|---|---|
| `a mechanism-diagnostic bridge` | `a diagnostic link to the mechanism` |
| `a structure-signal framework` | `a framework that links pore structure to the measured signal` |
| `a pore-coupling-informed interpretation` | `interpretation based on pore coupling` |
| `a robust indicator` | `an indicator that remains consistent across the tested cases` |
| `a new paradigm for prediction` | `a method that may support prediction under the tested conditions` |

## Author-Confirm Cases

Mark `author-confirm` when:

- the term's definition is not present in the source text;
- the definition requires choosing among scientific interpretations;
- the term may already have a field-specific meaning;
- the revision would change a regime boundary, equation meaning, mechanism, or claim strength.
