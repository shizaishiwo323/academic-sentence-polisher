# Simple Word Replacements

Use this file when a sentence sounds AI-like because it uses rare, decorative, or inflated vocabulary where a simpler academic word is equally precise.

## Core Rule

Prefer simple words only when they preserve technical precision. Do not replace a field-specific term with a vague general word.

## Common Replacements

| Avoid when possible | Prefer | Note |
|---|---|---|
| `utilize` | `use` | Default replacement |
| `leverage` | `use` | Avoid business-style tone |
| `elucidate` | `show`, `explain` | Use `explain` only when explanation is actually provided |
| `delineate` | `define`, `separate`, `distinguish` | Choose based on context |
| `facilitate` | `support`, `help`, `allow` | Avoid if it hides the mechanism |
| `manifest as` | `appear as`, `produce`, `take the form of` | Preserve physical meaning |
| `underscore` | `show`, `highlight` | `highlight` is acceptable for emphasis, not evidence |
| `intricate` | `complex` | Use only if complexity matters |
| `paradigm` | `framework`, or delete | Keep only for true conceptual shifts |
| `robustly demonstrate` | `show`, `support` | Use `robust` only with repeated tests |
| `giving rise to` | `producing`, `forming`, `leading to` | Avoid repeated template phrasing |
| `thereby revealing` | `indicating`, `suggesting`, or split sentence | Avoid adding discovery tone |
| `critical` | `important`, `relevant`, `controlling`, `required` | Choose only if evidence supports the role |
| `significant` | exact statistic, `large`, `clear`, or delete | Use `significant` for statistics only when intended |
| `substantial` | exact magnitude, `large`, or delete | Prefer quantified magnitude |

## Direct Verb Bank

For methods:

- `use`
- `scan`
- `segment`
- `calculate`
- `estimate`
- `compare`
- `extract`
- `simulate`
- `measure`

For results:

- `increase`
- `decrease`
- `shift`
- `merge`
- `separate`
- `remain`
- `vary`
- `localize`
- `expand`
- `narrow`

For interpretation:

- `indicate`
- `suggest`
- `support`
- `is consistent with`
- `may reflect`
- `can be interpreted as`

## Replacement Discipline

When replacing a word, check:

1. Does the replacement preserve the original evidence strength?
2. Does it keep the same technical relation?
3. Does it avoid adding a new claim?
4. Does the sentence become clearer rather than more ornate?

If the answer is uncertain, keep the original or mark `author-confirm`.
