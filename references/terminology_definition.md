# Terminology and Definition Control

## Terminology hierarchy

Prefer:

1. an explicit user glossary;
2. terms already defined and used consistently in the manuscript;
3. stable usage in target-journal articles;
4. recognized discipline-standard terminology;
5. a plain descriptive phrase marked `author-confirm`.

Do not invent a compact technical label merely to sound academic.

## Definition timing

Define a term when:

- it is central to the research question;
- it has a manuscript-specific meaning;
- multiple field meanings exist;
- an abbreviation will recur;
- the reader cannot interpret a result without it.

Do not overdefine common field terms for a specialist audience.

## Abbreviations

- define at first use according to journal policy;
- avoid abbreviations used only once or twice;
- preserve capitalization and plural form;
- do not redefine the same abbreviation differently;
- check Abstract and main text independently when the journal requires it.

## Consistency risks

Do not treat these as automatic synonyms:

- model / framework / scheme;
- accuracy / precision;
- sample / specimen;
- effect / response;
- validation / verification;
- correlation / relationship / causation;
- parameter / variable;
- sensitivity / responsiveness.

## Translation uncertainty

When Chinese permits multiple English terms:

```text
Preferred term:
Alternative:
Difference:
author-confirm:
```

Do not hide a technical ambiguity with a vague word.
