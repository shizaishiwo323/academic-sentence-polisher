# Overclaim Control

## Core rule

Preserve the source's evidence strength. Downgrade unsupported promotional language, but do not weaken a strong claim that is directly justified.

## High-risk changes

Never change:

- `suggests` to `demonstrates`;
- `indicates` to `proves`;
- `is consistent with` to `confirms`;
- `may`, `might`, or `could` to certainty;
- a result under tested conditions to a universal statement;
- association to causation;
- method demonstration to validated operational capability.

## Verb calibration

| Strong or risky | Possible alternatives |
|---|---|
| `prove` | `show`, `indicate`, `support` |
| `demonstrate` | `show`, `indicate`, when direct evidence is limited |
| `establish` | `support`, `define`, `provide` |
| `reveal` | `show`, `identify` |
| `confirm` | `support`, `is consistent with` |
| `validate` | `compare with`, `benchmark against`, unless true validation occurred |
| `enable` | `allow`, `support`, `may facilitate` |
| `govern` | `influence`, `contribute to`, `be associated with` |

## Intensifiers and value adjectives

Delete or quantify unsupported:

- `remarkably`;
- `critically`;
- `fundamentally`;
- `dramatically`;
- `robustly`;
- `clearly`;
- `novel`;
- `unprecedented`;
- `transformative`;
- `universal`;
- `comprehensive`.

`Significantly` should mean statistical significance when used that way. Otherwise give the magnitude or use a supported descriptive term.

## Scope

Retain:

- `in these simulations`;
- `under the tested conditions`;
- `within the measured range`;
- `in this cohort`;
- `at laboratory scale`.

Prefer a concrete contribution over a value judgment.
